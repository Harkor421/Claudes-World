## 📖 Sobre el proyecto

Simulación 3D de construcción de ciudades donde un agente de IA levanta autónomamente una colonia espacial en tiempo real. Explora, planifica y construye; cada decisión es visible y cada pensamiento queda registrado.

## ✨ Qué hace

- Agente autónomo movido por LLM que decide qué construir y dónde
- Log de pensamientos visible en pantalla mientras construye
- Mundo 3D con ciclo día/noche, nubes voxel y objetos espaciales
- Estado del mundo persistido en el servidor
- React Three Fiber + zustand · assets KayKit
